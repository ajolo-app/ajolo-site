Redeem a code

There are two kinds of codes. A creator code gives you a discount on the Pro subscription on the paywall. A company code unlocks Ajolo Pro if your employer has booked it for you.

In the app

  1. Install Ajolo from the App Store or Google Play.
  2. Open the Pro page of the app.
  3. Tap "Redeem code". For a company code, tap "Do you have a company code?".
  4. Enter the code and confirm.

With a creator code you then subscribe as usual in the App Store or on Google Play; the discount is shown there. Company codes are personal and can be redeemed only once. Pro access lasts until the end of the term your employer has booked.

Problems

If the app shows "Invalid code", check upper and lower case and whether the code was already redeemed. Otherwise write to app@ajolo.de and tell us the code (without a screenshot of your payment details).
