Code einlösen

Mit einem Code schaltest du Ajolo Pro frei. Das gilt für Codes von Creatorinnen und Creatoren und für Firmen-Codes deines Arbeitgebers.

In der App

  1. Installiere Ajolo aus dem App Store oder von Google Play.
  2. Öffne die Pro-Seite der App.
  3. Tippe auf „Code einlösen“. Bei einem Firmen-Code tippe auf „Hast du einen Firmen-Code?“.
  4. Gib den Code ein und bestätige.

Firmen-Codes sind persönlich und lassen sich nur einmal einlösen. Der Pro-Zugang gilt bis zum Ende der Laufzeit, die dein Arbeitgeber gebucht hat.

Probleme

Zeigt die App „Code ungültig“, prüfe Groß- und Kleinschreibung und ob der Code schon eingelöst wurde. Schreib uns sonst an app@ajolo.de und nenne den Code (ohne Screenshot deiner Zahlungsdaten).
